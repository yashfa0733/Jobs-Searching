CAREERCONNECT — WEB TECHNOLOGIES LAB 3
Job Recruitment Portal UI

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder: Job_Recruitment_Portal_Lab3.
3. Double-click index.html to open the website in Chrome, Edge or Firefox.
   Recommended: open the folder in VS Code and use the Live Server extension.

PROJECT PAGES
- index.html      Home / landing page
- register.html   Job seeker or employer registration
- login.html      Demo login form
- jobs.html       Search and filter job listings
- apply.html      Job application form with resume selection
- employer.html   Employer job posting form
- css/style.css   Shared responsive styling
- js/app.js       Form validation and page interactions

FEATURES
- Labels for all form controls
- Required, minlength, maxlength, input type and pattern validation
- Reusable input/button styles
- Focus, hover, error and success states
- Responsive two-column forms that become one column on smaller screens
- Styled resume upload field
- Job search and filtering
- Client-side demo registration/login using browser localStorage

IMPORTANT
This is a frontend Lab 3 project. There is no PHP/database/server backend.
Registration data is stored only in this browser's localStorage. Employer posts,
applications and uploaded resume files are validated in the browser only; they
are NOT sent to a company or saved on a server. Do not use real passwords.
An internet connection is needed only for the optional Google Fonts import.
